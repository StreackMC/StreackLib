## 0.4.7 更新日志

* SConfig
  * 为 JSON 增加宽松解析与根为数组（Array as Root）支持
  * 添加 RootName 特性支持
  * 修复按 "." 分割路径的算法错误
  * 优化临时文件算法
  * 添加 float 和 short 数据类型支持
  * 为节点提供 SConfig 类型支持
  * 新增 `getRawData()`，返回原始数据
  * 将多文件类型支持迁移到子类与接口实现
  * `putXXX()` 与 `remove()` 支持链式调用
  * 修复按字符串读取配置时返回空的问题
  * 为从字符串读取配置提供字符集选择支持
  * 添加 SNBT 和 NBT 支持

* StreackLib
  * 移除事件 `LIVE_TPS_REFRESHED`
  * 将默认 HTTPServer 的引用迁移到该类
  * 优化并复用 TPS 相关算法

* MCColor
  * 新增 `toHtmlBE(String)` 方法，用于处理基岩版中 "§n" 的不同行为
