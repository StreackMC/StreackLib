## What's Changed in `0.5.0`
* SConfig
  * 新增
    * 新增判断配置是否存在的方法 `isExist()`
    * 新增设置写入模式时的竞争状态锁，确保线程安全
    * 新增自动重载间隔和等待时长的自定义设置
    * 新增保存模式设置（`WRITE_MODE`）
    * 新增惰性初始化配置文件的选项，支持不初始化方法
  * 修复
    * 修复 Short 处理签名不正确的问题
    * 修复 `WRITE_MODE.MEMORY` 模式下可通过特定方法强制读取文件的问题
    * 修复 NBT 格式中非正常根结构处理表现异常的问题
    * 修复 `flush()` 中文件锁在特定情况下异常的问题
    * 修复自动重载在特定情况下大量占用资源的问题
    * 修复 Short 处理的声明类型错误问题
    * 修复部分线程可见性与原子性问题
    * 修复 INI 格式潜在的拒绝服务攻击漏洞
  * 优化与改进
    * 优化惰性初始化配置文件的逻辑
    * 合并同类方法，简化代码结构
    * 简化自动加载语法
    * 语义化部分功能的语法
    * 优化 JavaDoc
    * 优化代码架构与逻辑
    * 优化临时配置文件不再立即创建文件并占用磁盘 IO，改为惰性初始化
* HTTPServer
  * 新增
    * 新增 [Proxy Protocol](http://www.haproxy.org/download/1.8/doc/proxy-protocol.txt) 支持
    * 新增游戏内封禁同步功能
    * 新增内置 IP 封禁列表
  * 移除
    * 移除未使用的 JavaPlugin 引用
* StreackLib
  * 修复实时 TPS 高频更新导致的线程可见性问题，现在可以正确读取实时 TPS
  * IgnoredException
  * 修改为不受检异常（unchecked exception）
  * 提供静态方法用于过滤本异常或不受检异常
* 其他变更
  * 移除 SBukkit 类
  * 合并 types 和 utils 分类，现在统一为 utils
  * 迁移 后端初始化和游戏通信为统一 API，优化其结构
  * 修改 TPS 计算逻辑，完全移除旧版逻辑
  * 优化 整体代码质量
