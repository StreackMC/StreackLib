## What's Changed in `0.6.1`
* SdbDatabase
  * 修复 MERGE/UPDATE 命令无法被正确解析的问题
  * 统一化 API 的 public 标记
  * 修复 Context 预览路径（buildSQL）中，SELECT 命令的列名没有转义的问题
  * 修复 P0 安全缺陷：补全参数化执行路径（buildPreparedSQL）中所有标识符的反引号转义——表名（DELETE/CREATE/ALTER/DROP/TRUNCATE 及默认分支）、WITH 的 CTE 名、SELECT 投影列——使其与预览路径一致，彻底闭合 SQL 注入的标识符（表名/列名）注入面（此前实际执行的 SQL 中这些标识符为裸拼接）
