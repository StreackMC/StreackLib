## 功能列表
> 此处展示的功能非本前置库的可用全部功能，详情请[查看文档](./docs.md)。

* HTTP服务器：轻量易管理，支持多插件共享和单插件独享；
* 配置管理器：泛格式支持，自动重载，自动管理；
* [*更多……*](./docs.md)

## 下载

## 运行
### 加载器需求
目前支持以下加载器：
- [X] Paper
- [X] Spigot
- [ ] Fabric（未来可期）
- [ ] NeoForge（未来可期）

> 在代码中我们声明了需求版本`1.14+`，但代码始终在`1.21+`测试，不保证低版本可用性。
